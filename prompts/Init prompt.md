This project should be a program like pianobooster (https://github.com/pianobooster/PianoBooster)
But based on the web, so I can select the midi device through the browser and access midi-files and folders from the users pc. So completly client side.
Pianobooster built its own sheet rendering, Most of my midi-files are from musescore. So I want few options.
1. Midi + PDF render the pdf and use the midi as sound guide.
2. Musescore has its own standard to display the music, aswell as a open one. We could use one of these to  display the sheet and have the correct data for the music.
3. (maybe later) connect to musescore (do they have an api?) and access your sets, search and download music or add them to your favorites and learning sets (off this app, not musescore)

This might be a lot, so lets make a plan first.
